Interactive Calculator & Unit Converter

Project Description

This is a beginner-friendly Python CLI application that performs basic arithmetic operations, unit conversions, and currency conversions.

Features

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Kilometers to Miles conversion
6. Celsius to Fahrenheit conversion
7. INR to USD conversion
8. USD to INR conversion
9. Input validation
10. Interactive menu system

Technologies Used

- Python 3
- VS Code

Python Concepts Used

- Variables
- Data Types
- Conditional Statements
- While Loops
- Functions
- Try-Except
- User Input

How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run: python main.py

Conclusion

This project helped me understand Python fundamentals, functions, loops, conditional statements, and input validation through practical implementation.
